# JVS EXPRESS — PWA MVP

## O que está incluído
- Solicitação de entrega pelo cliente.
- Painel local para acompanhar pedidos e cadastrar motoristas.
- Central manual para registrar ofertas de Eu Entrego, Envios Extra, Shopee/SPX e outras.
- Cálculo simples de receita menos despesas registradas.
- Manifesto PWA e service worker para instalação e uso básico offline.

## Publicação
1. Crie um repositório GitHub para o projeto.
2. Envie `index.html`, `manifest.webmanifest` e `sw.js` para a raiz.
3. Ative GitHub Pages em Settings > Pages > Deploy from a branch > main > /(root).
4. Abra o endereço HTTPS no Safari do iPhone, toque em Compartilhar e escolha “Adicionar à Tela de Início”.
5. No Android, abra no Chrome e use “Instalar app” ou “Adicionar à tela inicial”.

## Limitação importante desta versão
Este é um MVP demonstrativo: os dados ficam no armazenamento local do navegador/aparelho. Não existe ainda login real, sincronização entre dispositivos, distribuição online de pedidos, rastreamento GPS em tempo real, pagamentos ou integração automática com plataformas externas.
Para operação comercial multiusuário, a próxima etapa é conectar backend com autenticação, banco de dados, permissões de cliente/administrador/motorista e notificações. Integrações com plataformas externas dependem de APIs e autorização oficiais.
